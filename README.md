# FloatTodo

Windows 桌面悬浮待办工具（WPF / .NET 10）。

## Today

- 顶部单行输入框：Enter 保存并清空，可连续添加；Esc 取消输入。空白内容不会保存。
- 点击待办整行即可完成或恢复，也可聚焦卡片后按空格；编辑框和操作按钮不会触发勾选。
- 鼠标悬停或键盘聚焦卡片时显示编辑、转换、删除按钮；按钮平时不占用文字宽度。
- 编辑按钮在当前行展开编辑框；Enter 保存、Esc 撤销、Shift+Enter 换行，也可使用保存/撤销按钮。未提交草稿不会因其他卡片变化而丢失。
- 勾选后播放轻量动画并将已完成项排到底部；取消勾选恢复原有顺序。遵循系统关闭动画的设置。
- 新增或行内编辑输入框获得键盘焦点时暂停贴边自动收起。
- 缩小卡片内边距、卡片间距和主视图边距，在窄窗口中优先展示内容。

## Scratch 与互相转换

- Scratch 支持添加、多行行内编辑和删除；Enter 保存、Shift+Enter 换行、Esc 取消。
- 卡片的双向箭头按钮将待办转为笔记，或将笔记转为未完成待办，追加到目标列表。保留 ID、文字（包括换行）和创建时间。
- 待办与笔记一起保存在 `%LOCALAPPDATA%\FloatTodo\todos.json`。旧版本的待办数组会兼容读取，并在下一次成功保存时升级为包含 `Todos` 和 `Notes` 的文档。
- 每次操作通过临时文件替换统一文档，转换不会分两次删除/新增。保存失败时不改变原数据，保留输入和编辑草稿；读取失败不会用空列表覆盖原文件。

## 验证

```powershell
dotnet build FloatTodo.slnx -c Release
dotnet test FloatTodo.slnx -c Release
```

测试包含存储、旧数据升级、双向转换的失败保护，以及 Windows STA 线程中的行内编辑、行点击、草稿保留和 Scratch 控件交互。真实鼠标悬停、中文输入法及贴边行为仍需桌面手动验收。
